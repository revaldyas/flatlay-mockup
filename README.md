# Flatlay Mockup

Upload card or poster designs, auto-arrange them into a tilted flat-lay grid mockup, then save as PNG or WebP. Built with Three.js. By [@revaldyas](https://github.com/revaldyas).

Unggah desain kartu/poster, tersusun otomatis jadi mockup flat-lay miring, lalu simpan sebagai PNG atau WebP.

## Features
- Canvas ratios 1:1, 4:5, 9:16, 16:9
- Uniform and Free layout (Free keeps each image's own ratio)
- Repeat or show each design once
- Rounded corners, focal length, tilt, shadow, glow, light direction, background colour
- Pan / rotate / light tools directly on the canvas
- PNG and WebP export (adjustable quality), up to 3072 px
- Indonesian and English
- Everything runs in your browser. Images are never uploaded.

## Run
No build step. Open `index.html` in a browser, or serve the folder with any static host.

```bash
npx serve .
```

## Deploy
Import the repo in Vercel (framework preset: Other). No settings needed.
